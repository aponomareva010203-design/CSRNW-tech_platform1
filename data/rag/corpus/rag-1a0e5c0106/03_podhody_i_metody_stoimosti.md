# Подходы и методы стоимостной оценки интеллектуальных активов

> Конспект для понимания отчётов оценщика и для управленческих прикидок. Итоговая рыночная
> стоимость для сделок — только в отчёте оценщика (135-ФЗ, ФСО).

## Три подхода (ФСО V, ФСО № 11, IVS 210)

| Подход | Логика | Когда уместен в вузе | Слабое место |
|---|---|---|---|
| Затратный | сколько стоит воссоздать или заменить актив | ранние РИД (УГТ 1–4), нет рынка и сделок; нижняя граница цены | не отражает рыночную ценность |
| Сравнительный | цены сделок с похожими активами | ПО, типовые технологии, есть база лицензионных сделок | мало открытых данных по сделкам в РФ |
| Доходный | приведённая стоимость будущих выгод от актива | есть продукт, рынок, план продаж; вклад в МТК, лицензия | чувствителен к прогнозу и ставке |

## Основные методы

### Освобождение от роялти (relief-from-royalty)
Стоимость = дисконтированная сумма роялти, которые владелец «сэкономил» бы, не платя за лицензию.

```
V = Σ (Выручка_t × Ставка роялти × (1 − налог)) / (1 + r)^t
```

Нужны: прогноз выручки продукта, рыночная ставка роялти для отрасли, срок полезного
использования (не дольше срока охраны), ставка дисконтирования с поправкой на риск.

### Дисконтирование денежных потоков (DCF) и метод избыточной прибыли
Выделяется часть денежного потока продукта, создаваемая именно технологией (за вычетом отдачи
на другие активы). Применяется, когда есть бизнес-модель МТК.

### Правило долей прибыли (profit split, «правило 25 %»)
Лицензиару — доля операционной прибыли лицензиата. Только как ориентир для переговоров:
правило критикуется и не заменяет оценку.

### Реальные опционы
Для ранних технологий: актив = право (но не обязанность) вложиться в следующий этап.
Отражает ценность гибкости: можно остановиться после неудачного этапа.

### Затраты замещения
Сумма затрат на создание аналогичного результата сегодня (НИОКР, охрана, время команды).
Нижняя граница для переговоров; удобна для учёта.

## Поправка на риск и готовность

Ставка дисконтирования для университетской технологии выше, чем для действующего бизнеса.
Практичный способ — **вероятностное взвешивание** по этапам: вероятность успешного перехода
на каждый следующий УГТ (см. модель «Шанс перехода на следующий УГТ» в разделе «Модели»).

```
rNPV = Σ P(достигнуть этапа t) × CF_t / (1 + r)^t
```

## Что выбрать под цель оценки

| Цель | Рекомендуемая оценка |
|---|---|
| Решение «поддерживать патент или отказаться» | скоринг + сравнение пошлин с ожидаемым доходом |
| Отбор в стартап-студию | скоринг технологического пакета (без денежной оценки) |
| Лицензионные переговоры | освобождение от роялти + правило долей прибыли как ориентир |
| Вклад права использования в капитал МТК | отчёт независимого оценщика (доходный подход, проверка затратным) |
| Учёт НМА | фактические затраты по стандарту учёта |
| Привлечение инвестиций в МТК | оценка компании целиком (венчурный метод), а не отдельного патента |

## Частые ошибки

- Оценивать патент отдельно от команды и рынка.
- Брать ставку роялти «из головы» без отраслевого обоснования.
- Считать срок дохода дольше срока действия патента.
- Использовать учётную (балансовую) стоимость как рыночную.
